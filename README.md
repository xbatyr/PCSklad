# ASTEX Stock — программа учёта для компьютерного магазина

Складской учёт, сборка ПК, разбор б/у системников, продажи и подсчёт прибыли.

Программа работает **на вашем компьютере**. Интернет не нужен. Все данные лежат
в одном файле на этом же компьютере и никуда не отправляются.

---

# ЧАСТЬ 1. КАК ЗАПУСТИТЬ

## Если у вас Mac

**Шаг 1.** Откройте папку `PCSklad`.

**Шаг 2.** Найдите файл **`start.command`** и дважды щёлкните по нему.

**Шаг 3.** Откроется чёрное окно с текстом. Это нормально — так и должно быть.
Подождите. При самом первом запуске программа устанавливает всё нужное, это занимает
**1–3 минуты**. В следующие разы будет запускаться за 5 секунд.

**Шаг 4.** Когда в чёрном окне появится такой текст — программа готова:

```
  ASTEX Stock запущен
  На этом компьютере:  http://localhost:8000
  С телефона по вайфаю: http://192.168.0.101:8000
  Остановить: Ctrl+C или закрыть окно
```

**Шаг 5.** Откройте браузер (Safari, Chrome — любой) и введите в адресную строку:

```
localhost:8000
```

**Шаг 6.** Браузер спросит имя и пароль. Введите их (где взять — см. раздел «Пароль»).

Готово, программа работает.

> ### ⚠️ Если Mac ругается «Не удаётся открыть, неопознанный разработчик»
>
> 1. Щёлкните по файлу `start.command` **правой** кнопкой мыши
>    (или обычной с зажатой клавишей Control).
> 2. В появившемся меню выберите **«Открыть»**.
> 3. Выскочит окошко — нажмите в нём **«Открыть»** ещё раз.
>
> Это нужно сделать один раз. Дальше будет открываться обычным двойным щелчком.

## Если у вас Windows

**Шаг 1.** Откройте папку `PCSklad`.

**Шаг 2.** Найдите файл **`start.bat`** и дважды щёлкните по нему.

**Шаг 3.** Откроется чёрное окно. Подождите 1–3 минуты при первом запуске.

**Шаг 4.** Откройте браузер и введите в адресную строку:

```
localhost:8000
```

**Шаг 5.** Введите имя и пароль.

> ### ⚠️ Если пишет «Python не найден»
>
> Значит, на компьютере не установлен Python. Установите его один раз:
>
> 1. Зайдите на сайт **python.org**
> 2. Нажмите большую кнопку **Download Python**
> 3. Запустите скачанный файл
> 4. **ВАЖНО:** в самом первом окне установщика внизу поставьте галочку
>    **«Add Python to PATH»**. Без неё работать не будет.
> 5. Нажмите Install и дождитесь конца
> 6. Перезагрузите компьютер и снова щёлкните по `start.bat`

## Как выключить программу

Просто **закройте чёрное окно** (крестик в углу).

Или нажмите в нём одновременно клавиши **Ctrl** и **C**.

Данные при этом никуда не денутся — они сохраняются сразу, как только вы что-то ввели.

## Важно понимать

* Пока чёрное окно открыто — программа работает.
* Закрыли окно — сайт перестаёт открываться.
* Компьютер выключили — то же самое.
* Чтобы работало постоянно, настройте автозапуск (см. ниже).

# ЧАСТЬ 2. ПАРОЛЬ

Программа спрашивает имя и пароль, чтобы посторонний не увидел ваши закупочные цены.

## Где посмотреть свой пароль

В папке `PCSklad` есть файл **`.env`**. Откройте его Блокнотом или TextEdit.
Внутри будет:

```
ADMIN_USER=admin
ADMIN_PASSWORD='ваш-пароль'
```

* `ADMIN_USER` — это **имя**, которое вводить в браузере
* `ADMIN_PASSWORD` — это **пароль**

> Файл `.env` может не отображаться, потому что имя начинается с точки — такие файлы
> система прячет. На Mac нажмите в папке **Cmd + Shift + Точка**, чтобы показать скрытые
> файлы. На Windows — вкладка «Вид» → галочка «Скрытые элементы».

## Как поменять пароль

1. **Закройте программу** (закройте чёрное окно).
2. Откройте файл `.env` Блокнотом.
3. Впишите новый пароль между кавычек: `ADMIN_PASSWORD='новый-пароль'`
4. Сохраните файл.
5. Запустите программу заново (двойной щелчок по `start.command` / `start.bat`).

> Обязательно перезапустите. Если просто обновить страницу в браузере, останется старый
> пароль.

## Браузер не спрашивает пароль заново

Так и задумано — браузер запоминает его до закрытия. Чтобы «выйти», закройте браузер
целиком.

# ЧАСТЬ 3. КАК ЗАХОДИТЬ С ТЕЛЕФОНА

Можно смотреть остатки с телефона или планшета, не подходя к компьютеру.

**Условие:** телефон и компьютер должны быть подключены к **одному и тому же Wi-Fi**.

**Шаг 1.** Запустите программу на компьютере.

**Шаг 2.** В чёрном окне найдите строчку «С телефона по вайфаю» и посмотрите адрес.
Он выглядит примерно так: `http://192.168.0.101:8000`

**Шаг 3.** На телефоне откройте браузер и введите этот адрес целиком.

**Шаг 4.** Введите имя и пароль — те же самые.

> Адрес может измениться после перезагрузки роутера. Если перестало открываться —
> посмотрите новый адрес в чёрном окне.

**Не открывается с телефона?**
* Проверьте, что телефон в том же Wi-Fi, а не в мобильном интернете
* Проверьте, что на компьютере программа запущена
* На Windows брандмауэр может блокировать — при первом запуске он спросит разрешение,
  нажмите «Разрешить доступ»

# ЧАСТЬ 4. КАК ПОЛЬЗОВАТЬСЯ

Наверху три вкладки: **ПК и Сетапы**, **Склад**, **Продажи**.
Над ними четыре плитки с общими цифрами.

## Плитки наверху

| Плитка | Что показывает |
|---|---|
| **ПК в наличии** | Сколько собранных компьютеров стоит непроданными |
| **Товаров на складе** | Сколько отдельных позиций лежит свободно |
| **Оценка склада** | Сколько денег заморожено в товаре (по закупочным ценам) |
| **Прибыль с продаж** | Сколько заработали за всё время |

## Вкладка «ПК и Сетапы» — готовые компьютеры

### Собрать новый компьютер

1. Нажмите синюю кнопку **«+ Собрать ПК / Сетап»**
2. Впишите название — например, `ASTEX Gaming 5600 / RTX 4060`
3. Впишите цену, за которую будете продавать
4. Ниже строчки с комплектующими. В каждой:
   * **Тип** — комплектующая или периферия
   * **Категория** — процессор, видеокарта, память и так далее
   * **Наименование** — точная модель
   * **Закуп** — за сколько вы её купили
   * **Розница** — за сколько продали бы отдельно (можно не заполнять)
5. Не хватает строчек — нажмите **«+ Позиция»**
6. Лишняя строчка — нажмите значок корзины справа от неё
7. Внизу окна сразу видно себестоимость и вашу маржу
8. Нажмите **«Создать сборку»**

### Взять деталь со склада в сборку

В окне сборки есть выпадающий список **«＋ Взять со склада»**. Нажмите на него и
выберите нужную деталь — она подставится в сборку и уйдёт со склада.

Так работают детали от разобранных б/у системников.

### Поменять деталь в готовом компьютере

1. Нажмите **«Пересобрать»** на карточке компьютера
2. Чтобы **убрать** деталь — нажмите корзину напротив неё. Она вернётся на склад
   и её можно будет поставить в другой компьютер или продать отдельно.
3. Чтобы **добавить** — «+ Позиция» или «Взять со склада»
4. Чтобы **заменить** — просто перепишите название и цену в строчке
5. Нажмите **«Сохранить»**

### Быстро поменять цену одной детали

Прямо на карточке компьютера в списке деталей **щёлкните по цене** детали.
Появится окошко для ввода новой. Себестоимость пересчитается сразу.

### Продать компьютер

1. Нажмите зелёную кнопку **«Продать»**
2. Впишите цену, за которую реально продали (если торговались — ставьте итоговую)
3. Проверьте **дату и время**. По умолчанию стоит текущий момент. Если продали вчера,
   а внести забыли — поменяйте дату здесь.
4. Видно прибыль по сделке
5. Нажмите **«Продать»**

Все детали этого компьютера автоматически спишутся со склада.

### Продали по ошибке

На карточке проданного компьютера нажмите **«Отменить продажу»**. Компьютер вернётся
в наличие, детали — в сборку, прибыль пересчитается.

### Отправить состав клиенту

Нажмите значок с двумя квадратиками на карточке — состав скопируется текстом.
Вставьте в WhatsApp или Telegram.

### Удалить компьютер

Значок корзины на карточке. Детали при этом **не пропадут** — вернутся на свободный склад.

> Проданный компьютер удалить нельзя — он нужен для отчёта по прибыли.
> Сначала отмените продажу.

## Вкладка «Склад» — комплектующие, периферия, услуги

### Оприходовать товар (купили новое)

1. Нажмите голубую кнопку **«+ Оприходовать товар»**
2. Выберите тип и категорию
3. Впишите наименование, цену закупа, цену розницы
4. **Количество** — если купили 10 одинаковых мышек, поставьте 10.
   Создадутся 10 отдельных позиций, каждую можно продать отдельно.
5. **Дата покупки** и **Откуда пришла** — необязательно, но полезно
6. Нажмите **«Оприходовать»**

### Принять б/у системник на разбор ⭐

Это для случая, когда вы **купили у клиента б/у компьютер**, чтобы разобрать его
на запчасти.

1. Нажмите жёлтую кнопку **«Принять б/у ПК на разбор»**
2. В поле **«Откуда системник»** впишите, у кого купили — например,
   `Б/У ПК от клиента Асхат, +7 777 123 45 67`.
   Эта пометка запишется каждой детали, и потом будет видно, откуда она.
3. Поставьте **дату покупки**
4. Перечислите, что внутри системника: процессор, видеокарта, память и так далее.
   У каждой детали впишите **свою цену закупа**.
5. **Внизу жёлтым показывается сумма.** Она должна примерно сойтись с той суммой,
   за которую вы взяли системник целиком. Это чтобы вы могли себя проверить.
6. Нажмите **«Разобрать на склад»**

**Что произойдёт:** все комплектующие лягут на склад **по отдельности**.
Отдельной карточки компьютера не появится. Каждую деталь теперь можно поставить
в любую сборку или продать отдельно.

В таблице склада под каждой такой деталью оранжевым будет подпись, из какого
системника она пришла.

### Записать услугу (ремонт, чистка)

1. Нажмите фиолетовую кнопку **«Услуга»**
2. **Что сделали** — например, `Чистка от пыли и замена термопасты`
3. Выберите категорию: ремонт, обслуживание, сборка, диагностика, ПО
4. **Цена для клиента** — сколько взяли
5. **Расходы** — сколько потратили на запчасти или материалы (можно 0)
6. Проверьте дату
7. Нажмите **«Записать»**

Услуга сразу попадёт в продажи и прибыль.

### Изменить товар

Нажмите значок карандаша в строке товара. Можно поменять название, категорию, цены,
дату покупки.

**Это работает и для деталей, которые стоят в собранном компьютере** — кнопка
«Изменить». Себестоимость того компьютера пересчитается сама.

### Продать товар со склада

1. Нажмите зелёную кнопку **«Продать»** в строке товара
2. Впишите цену и при необходимости поменяйте дату
3. Видно прибыль со сделки
4. Подтвердите

### Найти нужное

* **Строка поиска** справа сверху — вводите часть названия
* **Фильтры**: Все, Комплектующие, Периферия, Услуги, В наличии, В сборках, Продано
* **Категория** — вторая строчка фильтров: только видеокарты, только процессоры и так далее

### Колонки таблицы

| Колонка | Что означает |
|---|---|
| Наименование | Модель, номер позиции, тип |
| Категория | Процессор, видеокарта и т.д. |
| Закуп | За сколько купили |
| Розница | За сколько продаёте |
| Статус | На складе / В сборке / Продано |
| Расположение | Свободный склад или название компьютера. Оранжевым — откуда пришла |
| Куплена | Дата покупки |
| Изменена | Когда последний раз правили эту позицию |

## Вкладка «Продажи» — что и когда продали

Список всех сделок: компьютеры, отдельные товары и услуги вместе.

### Выбрать период

**Быстрые кнопки:** Сегодня, 7 дней, 30 дней, Всё время.

**Свой период:** два поля с датами — выберите «с» и «по», нажмите **«Показать»**.
Например, чтобы посмотреть весь прошлый месяц.

Справа написано, какой период сейчас показан.

### Три плитки

* **Выручка** — сколько денег получили
* **Себестоимость** — во сколько вам обошлось
* **Прибыль** — разница, ваш заработок

По каждой сделке в списке те же три цифры.

## Excel — выгрузка и загрузка

### Скачать всё в Excel

Нажмите зелёную кнопку **«Excel»** справа вверху, рядом со значком обновления.

Скачается файл с тремя листами:

* **Сборки** — все компьютеры с себестоимостью и маржой
* **Склад** — все позиции со статусами, датами и пометками, откуда пришли
* **Продажи** — все сделки с итоговой строкой внизу

Шапка закреплена, фильтры включены — можно сразу сортировать и считать в Excel.
Пригодится для отчёта, для бухгалтера или чтобы посчитать что-то своими формулами.

### Загрузить товары из Excel

Удобно, когда пришла большая партия и вбивать руками долго.

1. Нажмите значок **со стрелкой вверх** справа вверху
2. Нажмите **«Скачать шаблон»** — получите файл с готовыми колонками и примером
3. Откройте шаблон в Excel, удалите строки-примеры, впишите свои товары.
   Обязательны только **Наименование** и **Закуп**, остальное можно оставить пустым.
4. Сохраните файл
5. Вернитесь в программу, нажмите на поле выбора и укажите заполненный файл
6. Программа покажет, сколько позиций нашла и на какую сумму. Если что-то не поняла —
   напишет об этом жёлтым, но остальные строки всё равно загрузятся.
7. Нажмите **«Загрузить на склад»**

> **Загрузка только добавляет.** Ничего из того, что уже на складе, не изменится
> и не удалится. Если загрузили лишнее — просто удалите эти позиции вручную.

Программа понимает написание в любом регистре, числа с пробелами вроде `85 000`,
пустые строки пропускает. Свой же выгруженный файл читает обратно без правок.

## Горячие клавиши

Для тех, кто работает быстро. Нажмите **?** в программе, чтобы увидеть список.

| Клавиша | Что делает |
|---|---|
| `1` `2` `3` | Переключить вкладку |
| `N` | Создать сборку или товар (смотря где находитесь) |
| `B` | Принять б/у ПК на разбор |
| `U` | Записать услугу |
| `/` | Перейти в поиск |
| `R` | Обновить данные |
| `Esc` | Закрыть окно |
| `?` | Показать эту таблицу |

Раскладка не важна — работают те же клавиши и в русской. Когда курсор стоит в поле
ввода, клавиши не срабатывают, можно спокойно печатать.

## Мелочи, которые упрощают работу

* **Сортировка.** Щёлкните по заголовку колонки в таблице склада — отсортируется.
  Ещё раз — в обратную сторону.
* **Итог под таблицей.** Показывает, сколько позиций отобрано и на какую сумму —
  удобно при фильтрах.
* **Поиск ищет и по пометке «откуда пришла»** — можно найти все детали из одного
  б/у системника, введя имя клиента.
* **Данные сами обновляются** раз в минуту. Если программа открыта на компьютере
  и на телефоне, цифры не разойдутся.

# ЧАСТЬ 5. РЕЗЕРВНЫЕ КОПИИ — ОБЯЗАТЕЛЬНО ПРОЧИТАЙТЕ

Вся ваша история закупок и продаж лежит в **одном файле**: `astex_stock.db`.

Если сломается диск или компьютер украдут — данные пропадут. Второго экземпляра нигде нет.

## Как сделать копию (Mac)

Дважды щёлкните по файлу **`backup.command`**.

Копия появится в папке `backups` внутри `PCSklad`. Хранятся последние 14 копий.

**Делайте это раз в неделю.** Занимает 2 секунды.

## Как сделать копию (Windows)

1. Закройте программу
2. Скопируйте файл `astex_stock.db` в надёжное место

## Копию лучше держать не только на компьютере

Раз в месяц копируйте файл из папки `backups` ещё и на флешку, или закидывайте
в облако. Если сгорит компьютер, копия рядом с ним не поможет.

## Как восстановить из копии

1. Закройте программу
2. Зайдите в папку `backups`
3. Найдите нужную копию (в названии дата и время)
4. Скопируйте её в папку `PCSklad`
5. Переименуйте в `astex_stock.db`, заменив старый файл
6. Запустите программу

# ЧАСТЬ 6. АВТОЗАПУСК ПРИ ВКЛЮЧЕНИИ КОМПЬЮТЕРА

Чтобы не запускать вручную каждое утро.

# ЧАСТЬ 7. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Сайт не открывается, браузер пишет «Не удаётся подключиться»

Программа не запущена. Щёлкните по `start.command` (Mac) или `start.bat` (Windows)
и дождитесь появления текста в чёрном окне.

### В чёрном окне написано «Порт 8000 занят» или «Address already in use»

Программа уже запущена в другом окне. Найдите его и используйте, либо закройте все
чёрные окна и запустите заново.

### Не помню пароль

Откройте файл `.env` Блокнотом — пароль написан там (см. Часть 2).

### Ввожу пароль, но не пускает

* Проверьте раскладку клавиатуры и заглавные буквы — пароль их различает
* Проверьте, нет ли лишнего пробела в конце
* Попробуйте открыть в режиме инкогнито (браузер мог запомнить старый пароль)

### Программа запускается, но страница пустая или сломанная

Обновите страницу клавишами **Ctrl + F5** (Windows) или **Cmd + Shift + R** (Mac).

### Не открывается с телефона

См. Часть 3 — телефон и компьютер должны быть в одном Wi-Fi.

### Случайно удалил компьютер или товар

Восстановить нельзя. Внесите заново или восстановите из резервной копии (Часть 5).

### Случайно продал не то

Нажмите **«Отменить продажу»** — на карточке компьютера или в строке товара.

### Пропали все данные

Восстановите из резервной копии (Часть 5).

# ЧАСТЬ 9. ДЛЯ ТЕХНИЧЕСКОГО СПЕЦИАЛИСТА

Если понадобится дорабатывать программу.

**Стек:** FastAPI + SQLAlchemy + SQLite, фронтенд — Tailwind CSS и Alpine.js
в одном шаблоне без сборки.

**Ручной запуск:**

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # вписать ADMIN_PASSWORD
python seed.py                     # демо-данные
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Документация API: http://localhost:8000/docs

**Основные методы:**

| Метод | Путь | Назначение |
|---|---|---|
| `GET/POST` | `/api/pcs` | Список и создание сборок |
| `PUT` | `/api/pcs/{id}` | Пересборка (swap деталей) |
| `POST` | `/api/pcs/{id}/sell` | Продажа, тело `{"price":…, "sold_at":…}` |
| `POST` | `/api/pcs/{id}/unsell` | Отмена продажи |
| `POST` | `/api/intake` | Приём б/у ПК на разбор |
| `POST` | `/api/services/sell` | Разовая услуга |
| `GET` | `/api/items` | Позиции, фильтры `type`, `status`, `category`, `q` |
| `PUT` | `/api/items/{id}` | Правка, в том числе деталей в сборке |
| `GET` | `/api/sales` | Продажи, `period` или `date_from`/`date_to` |
| `GET` | `/api/stats` | Метрики дашборда |
| `GET` | `/api/export.xlsx` | Выгрузка всей базы в Excel |
| `GET` | `/api/import-template.xlsx` | Шаблон для заполнения |
| `POST` | `/api/import` | Загрузка из Excel, `?dry_run=true` — проверка без записи |

**Расчёт прибыли:**

```
прибыль = (цена проданных ПК − закуп их деталей)
        + (цена штучных продаж − их закуп)
        + (цена услуг − расходы по ним)
```

**Валюта** меняется одной строкой в начале `<script>` в `templates/index.html`:

```js
const CURRENCY = '₸';
```

# ASTEX Stock

Учёт склада компьютерного магазина: готовые ПК и сетапы, пересборка (swap деталей),
свободный склад комплектующих и периферии, розничные продажи и аналитика прибыли.

**Стек:** FastAPI + SQLAlchemy + SQLite · Tailwind CSS (CDN) + Alpine.js в одном шаблоне.
Сборка Node.js не нужна.

---

## Запуск

```bash
cd PCSklad

python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python seed.py                     # демо-данные (необязательно)
uvicorn main:app --reload
```

Открыть: **http://127.0.0.1:8000** · Swagger: http://127.0.0.1:8000/docs

База (`astex_stock.db`) создаётся автоматически при первом старте.
`python seed.py --force` — снести данные и залить демо заново.

## API

### Готовые ПК
| Метод | Путь | Описание |
|---|---|---|
| `GET`  | `/api/pcs?status=all\|in_stock\|sold` | Список ПК с вложенными позициями, себестоимостью и маржой |
| `GET`  | `/api/pcs/{id}`        | Одна сборка |
| `POST` | `/api/pcs`             | Создать ПК (`in_stock`) + позиции (`in_assembly`) |
| `PUT`  | `/api/pcs/{id}`        | **Пересборка / swap** |
| `POST` | `/api/pcs/{id}/sell`   | Продажа в 1 клик с каскадным списанием позиций |

### Склад и розница
| Метод | Путь | Описание |
|---|---|---|
| `GET`  | `/api/items?type=&status=&q=` | Товары с фильтрами и названием ПК-владельца |
| `POST` | `/api/items`                  | Оприходование на свободный склад |
| `PUT`  | `/api/items/{id}`             | Правка карточки товара |
| `POST` | `/api/items/{id}/quick-sell`  | Быстрая розничная продажа (тело: `{"price": 14500}`) |

### Прочее
`GET /api/stats` — метрики дашборда · `GET /api/meta` — справочник категорий.

## Логика swap (`PUT /api/pcs/{id}`)

Приходит **полный** новый состав сборки. Позиция определяется по `id`:

* `id` есть и деталь уже в этой сборке → поля обновляются на месте (апгрейд);
* `id` есть, деталь лежит на свободном складе → привязывается к ПК, статус `in_assembly`;
* `id` нет → создаётся новая позиция;
* деталь была в сборке, но её нет в новом списке → `pc_id = NULL`, статус `in_stock`
  (возврат на свободный склад).

Проданный ПК пересобирать нельзя (400). Попытка забрать деталь из чужой сборки или
проданную позицию — 400 с откатом всей транзакции.

## Расчёт прибыли (`/api/stats`)

```
profit = (Σ sell_price проданных ПК − Σ cost_price их деталей)
       + (Σ retail_price штучных продаж − Σ их cost_price)

stock_value = Σ cost_price всех непроданных позиций (склад + сборки)
```
